    AI Market Narratives & Hybrid Context Engine (apps.narratives)

    1. Executive Summary & Architectural Mission

    The AI Market Narratives & Hybrid Context Engine serves as the automated financial research, executive intelligence, and institutional surveillance layer for global commodity derivatives.

    Traditional LLM implementations in financial analysis suffer from two fatal vulnerabilities: 1. Mathematical Hallucination: Large Language Models perform erratic mental arithmetic when calculating calendar spreads, multi-horizon returns, or volatility percentiles. 2. Lookahead & Data Decoupling: Language models ingest unversioned news and market commentary without point-in-time synchronization with forward curves and physical balances.

    To address these vulnerabilities, apps.narratives strictly adheres to Core Directive 3 (Deterministic Arithmetic Precedes LLM Reasoning) and Core Directive 2 (Point-in-Time Correctness): - Zero Mental Math: All multi-horizon returns, realized volatility regimes, ATR values, 20Y seasonality tenure win rates, PCHIP spline forward curves, and CFTC positioning metrics are computed deterministically by apps.quant_engine before any prompt is assembled. - Strict Ground-Truth Evidence Package: The Context Builder aggregates and freezes numerical features, macro catalyst prints, and news sentiment into an immutable Section 21 prompt package. - Pluggable LLM Provider Contract: Isolated behind an abstract provider interface (BaseLLMProvider), allowing hot-swapping between Static (Offline Deterministic), Google Gemini 2.0 Flash, Anthropic Claude 3.5 Sonnet, OpenAI GPT-4o, and local Ollama (Llama 3) without changing downstream logic. - Automated Regulatory Compliance: Every generated briefing and flash alert is automatically stamped with the institutional non-advice regulatory notice (Directive 4).

    2. Domain Data Models

    The persistence layer (apps.narratives.models) extends UUIDModel and PointInTimeModel:

    MarketNarrative

    Field Type Description
    id UUIDField Primary key identifier (RFC 4122 v4).
    commodity ForeignKey Target CommodityMaster (null for cross-commodity / macro briefs).
    narrative_type CharField Categorical briefing type: MORNING_BRIEF, EXECUTIVE_FLASH, SUPPLY_DEMAND, RISK_ALERT, OUTLIER_DIVERGENCE.
    headline CharField(255) Institutional research headline summarizing key market dynamic.
    executive_summary TextField Concise 2-3 sentence executive synopsis.
    market_context_body TextField Structured Markdown narrative covering market structure, term structure, fundamentals, and catalysts.
    key_bullet_points JSONField List of high-conviction quantitative takeaway bullets.
    risk_factors JSONField Explicit surveillance risk vectors, asymmetries, and catalyst triggers.
    evidence_snapshot JSONField Immutable snapshot of the normalized quantitative context ingested during generation.
    llm_provider CharField(64) Provider adapter identifier (e.g. static, gemini, claude, openai, ollama).
    llm_model CharField(64) Model version identifier (e.g. gemini-2.0-flash, claude-3-5-sonnet-20241022).
    prompt_tokens PositiveIntegerField Token count of input prompt context.
    completion_tokens PositiveIntegerField Token count of generated output.
    status CharField(16) Lifecycle state: DRAFT, PUBLISHED, ARCHIVED.
    compliance_disclaimer TextField Non-negotiable standard regulatory compliance notice.
    availability_time DateTimeField Exact point-in-time when data became accessible to the market.

    3. Pluggable LLM Provider Architecture

    Every LLM integration implements the abstract base contract defined in apps.narratives.providers.base.BaseLLMProvider:

    class BaseLLMProvider(ABC):
    provider_name: str = "base"
    default_model: str = "default"

    @abstractmethod
    def generate_narrative(
        self,
        prompt: str,
        system_instruction: str,
        context_dict: Dict[str, Any],
        narrative_type: str = "MORNING_BRIEF",
    ) -> LLMResponse:
        pass

    Supported Provider Implementations

    1. StaticLLMProvider (static):
    2. Deterministic rule-based synthesizer requiring zero external network calls or API keys.
    3. Evaluates multi-factor composite scores, contango/backwardation slopes, RSI percentiles, and divergences to generate high-grade institutional research.
    4. Serves as the default offline provider, ensuring 100% test suite reliability.
    5. GeminiLLMProvider (gemini):
    6. Google Gemini 2.0 / 1.5 Flash via REST API using httpx.
    7. Utilizes strict JSON response schema generation.
    8. Automatic fallback to StaticLLMProvider if GEMINI_API_KEY is absent or remote service times out.
    9. ClaudeLLMProvider (claude):
    10. Anthropic Claude 3.5 Sonnet via /v1/messages.
    11. High-precision macro reasoning with graceful offline fallback.
    12. OpenAILLMProvider (openai):
    13. OpenAI GPT-4o via /v1/chat/completions with JSON Mode enforcement.
    14. OllamaLLMProvider (ollama):
    15. Local on-premise execution via http://localhost:11434/api/generate with zero data egress.

    4. Hybrid Context Compilation Engine

    The Context Builder (apps.narratives.services.context_builder.build_narrative_context) gathers verified inputs across 4 platform sub-systems:

    1. Vectorized Quantitative Evidence:
    2. Spot settlement price and multi-horizon returns (1D, 5D, 21D, 63D).
    3. Realized volatility % and regime classification.
    4. Forward curve term structure slope (STRONG_BACKWARDATION, CONTANGO), prompt spread (M1-M2), and 1-year roll yield.
    5. Real-Time Technical Indicator Posture:
    6. Triple EMA structure (20, 50, 200 EMA), slope, and Wilder ADX(14) trend state.
    7. Wilder RSI(14) percentile and Appel MACD momentum state.
    8. Relative Volume (RVOL) and Volume Shock Z-score.
    9. Physical Fundamentals & Inventory Balances:
    10. Reported inventory levels (e.g. EIA Cushing Crude Stocks, Natural Gas Underground Storage).
    11. Seasonal percentile vs. 5-year historical normal and physical balance regime.
    12. CFTC Commitment of Traders (COT):
    13. Disaggregated speculative positioning: Managed Money Net, Commercial Net, and positioning crowding regime.
    14. Macro Catalysts & Sentiment Wire:
    15. Scheduled high-impact releases (OPEC meetings, USDA WASDE, FOMC rate decisions, EIA Weekly Petroleum).
    16. Tagged news flow with commodity-specific sentiment polarity scores.

    5. Management Commands & Operational Workflows

    Seeding Baseline Market Narratives

    Seed baseline morning briefings, supply/demand balance commentaries, and risk alerts idempotently for benchmark commodities (CL, BRENT, NG, GOLD, CORN):

    .\.venv\Scripts\python.exe manage.py seed_narratives --clear

    On-Demand Narrative Generation via CLI

    Generate an evidence-grounded briefing on demand:

    # Generate WTI Morning Briefing using default provider
.\.venv\Scripts\python.exe manage.py generate_narrative --commodity CL --type MORNING_BRIEF

# Generate Natural Gas Risk Alert using Gemini
.\.venv\Scripts\python.exe manage.py generate_narrative --commodity NG --type RISK_ALERT --provider gemini

# Generate Gold Executive Flash using Ollama
.\.venv\Scripts\python.exe manage.py generate_narrative --commodity GOLD --type EXECUTIVE_FLASH --provider ollama
